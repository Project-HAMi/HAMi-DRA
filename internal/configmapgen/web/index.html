ConfigMap 生成器

可视化维护多个批量分组和多个节点覆盖。关键字段直出，UUID、minor、PCIe 等非关键项自动生成；需要细调时可直接改原始配置。

全局配置

这里放 ConfigMap 元信息和全局节点选择，下面可视化增删多个 group 和 node override。

批量分组 Groups

每个 group 通过 selector 匹配一批节点，并批量生成一组设备。

节点覆盖 Nodes

按节点名精确定义或覆盖设备，同名设备会覆盖 group 里对应字段。

自动生成： `uuid`、`minor`、`attr.project-hami.io/minor`、`pcieBusID`
默认保留： `requestPolicy`、`driverVersion`、CUDA 相关字段
